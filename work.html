Receipt Matching Application

Python • OCR • Automation

The Challenge

A bookkeeper was tired of always playing catch-up with receipt reconciliation. Manually tracking receipts took hours!

The Solution

Built a custom desktop application using Python, PySide6, and OCR technology that automatically matches receipts to transactions. The app scans receipts, extracts key data, and pairs them with bank statement transactions in seconds.

The Results

  • ✅ Reduced processing time
  • ✅ Eliminated manual data entry errors
  • ✅ Freed up time for strategic financial analysis

Automated Burden Report - Excel

Power Query • Excel • Automation

The Challenge

A construction company needed to process complex overtime allocation and job cost tracking across multiple projects. Manual calculations were time-consuming and prone to errors, especially with varying pay rates and project codes.

The Solution

Developed a comprehensive Power Query system that automatically processes payroll data, allocates overtime correctly, and tracks costs by project. The system handles complex business rules and generates ready-to-use reports.

The Results

  • ✅ Reduced payroll processing time by 75%
  • ✅ Eliminated manual calculation errors
  • ✅ Provided real-time job cost visibility
  • ✅ Automated multi-project overtime allocation
